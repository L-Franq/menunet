# MenuNet - Sistema Web de cardápio digital
*web address*: https://menunet.com 

É um Saas projectado para dar suporte a restaurantes no que diz respeito a montagem, apresentação e acesso, tanto por clientes como por restaurantes, ao menu.

---

# Sobre o Sistema 

Para a utilização do sistema não são requeridas instalação de quaisquer ferramentas por parte dos utilizadores, ou conhecimentos profundos em tecnologia. Possui uma interface simples e fluxo de utilização claro, o que faz do *MenuNet* um sistema flexível e moderno.

Com o sistema é possível:

- Uma apresentação visual do menu, bem descritiva;
- Reprodução em código Qr que, representa unicamente o menu de cada restaurante;
- Acessar um histórico de pratos,  o que torna possível reaproveitar pratos de menus anteriores;
- No menu, o cliente pode filtrar a busca por intervalos de preços, bem como categoria (comida, bebida);
- E até manejar informações do próprio restaurante.

O sistema está completo, mas com uma visão de actualizções graduais conforme a necessidade do negócio. Tanto em termos de infra-estrutura como nas tecnologias utilizadas.

# Funcionalidades em Potencial

- Marcação de pedidos por mesa;
- controlo de seleção Takeaway;
- Relatórios de demanda.

## Pré-requisitos
- Node.js instalado

- Git (opcional)

### Passos
```bash
git clone https://github.com/L-Franq/menunet.git

cd menunet
npm install

npm start ou npm run dev
```
